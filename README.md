Salesforce Administrator Bootcamp - KBA Mock Exams
This repository contains mock KBA exams I created while completing the Per Scholas Salesforce Administrator Bootcamp.
The goal is to help our class prepare for each week's Knowledge Based Assessment (KBA) by practicing questions based on the topics and concepts covered in class.

🎯 Purpose
These mock exams are designed to help with:
- Reviewing important Salesforce concepts before each KBA
- Getting comfortable with the types of questions we may encounter
- Improving memorization and knowledge retention
- Reducing test anxiety through repeated practice
- Identifying topics that may need additional review

📚 Mock Exams
Each exam corresponds to material covered during the bootcamp. Additional exams will be added as we progress through the course.
Disclaimer: These are unofficial practice questions created for study purposes. They are not actual Per Scholas KBA questions and are not guaranteed to appear on an assessment.
Use these mock exams as a supplement to the official course materials and your own studying.
